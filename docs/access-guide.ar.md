# الحصول على المفاتيح واستخدام القائمة

## أنواع الوصول

- `no_key`: استخدم base_url وفق التوثيق. لا توجد قيمة مفتاح كي تجمعها.
- `api_key`: افتح get_access_url، واختر الخطة المجانية، وأنشئ مفتاحًا باسم حسابك. المفتاح شخصي ولا يُنشر في المستودع.
- `account_token`: أنشئ مشروعك المجاني ورمزًا محدود الصلاحيات، أو استخدم OAuth/service account كما يحدد المزود. بيانات حسابك لا تمنحها تلقائيًا لمستخدم آخر.
- `username`: GeoNames يتطلب اسم مستخدمك وتفعيل web services؛ لا تستخدم اسم demo.
- `public_demo_key`: القيمة منشورة رسميًا للتعليم/الاختبار في الملف المخصص. النطاق أضيق من مفتاح حساب خاص أو ترخيص إنتاج.
- `api_key_or_no_key`: يوجد مسار مفتوح ومسار تسجيل بحصة مختلفة؛ لا تفترض تطابقهما.
- `api_key_or_public_demo`: مفتاح مسجل خاص أوdemo رسمي؛ حصة المثال لا تساوي تلقائيًا حصة المفتاح المسجل.

## خطوات الاختيار

1. ابحث حسب المجال وauth وcommercial_use؛ لا تختَر خدمة غير تجارية لتطبيق تجاري.
2. اقرأ quota وreset وlimitations_ar، ثم افتح المصدر الرسمي للتأكد من استمرار الخطة.
3. استخدم Free/Spark/Core/Build المذكورة، حسب المزود. لا تفعّل تجربة مدفوعة أوoverages أوautoscaling بلا قصد.
4. احفظ مفاتيح الحساب في متغيرات البيئة أوsecrets manager؛ استخدم server-side للسرّيات. بعض publishable keys علنية بطبيعتها لكن تحتاج سياسات وصول صحيحة.
5. التزم Retry-After والحدود المشتركة على مستوى الحساب/IP/project. تدوير المفاتيح أوتعدد الحسابات ليس وسيلة لتجديد الحصة.

## أمثلة عامة منشورة رسميًا

```sh
curl 'https://api.nasa.gov/planetary/apod?api_key=DEMO_KEY'
curl 'https://www.themealdb.com/api/json/v1/1/search.php?s=Arrabiata'
curl 'https://api.dictionaryapi.dev/api/v2/entries/en/hello'
```

مفتاح NASA التجريبي محدود بـ30 طلبًا/ساعة و50/يوم لكل IP. مفتاح TheMealDB العام للتطوير/التعليم؛ نشر app store يحتاج supporter. ملف `public-demo-keys.json` يضم أمثلة للاستخدام العام نشرها أصحاب الخدمات، ولا يحوي أسرار الحسابات.

**لم تُنشأ مفاتيح شخصية لكل هذه الخدمات.** ذلك يحتاج تسجيل المستخدم وموافقاته والتحقق من البريد/الهاتف أوشروط خدمة كل مزود. القائمة تعطيك الطريق القانوني للحصول عليها والحدود المثبتة، ولا تدعي أنها مئات مفاتيح جاهزة مشتركة.

أُضيف مثال OCR.space الرسمي بالمفتاح `helloworld` ومثال GovInfo باستخدام `DEMO_KEY`. لا نعد إعادة استخدام نفس القيمة لدى خدمة أخرى مفتاحًا مختلفًا. المفاتيح المخصصة لحسابك تبقى خاصة حتى لو كان الاشتراك مجانيًا.
